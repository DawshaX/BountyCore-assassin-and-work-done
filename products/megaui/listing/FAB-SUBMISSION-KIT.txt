MegaUI - Game UI Design System
================================

THE COMPLETE GAME UI KIT - 4 THEMES, 2672 COMPONENTS, 84 SCREENS IN 4K.


WHAT'S INSIDE
-------------
* 4 hand-crafted themes: Dark Fantasy, Sci-Fi Neon, Clean Royal, Pixel Retro.
* 2672 editable vector components (SVG) + the same 2672 PNGs at 4x resolution.
* 9 button shapes x 4 states x 4 kinds, per theme.
* 244 original icons on a shared 24px grid, tinted per theme.
* Bars, rings, slots (4 sizes x rarities), panels, dialogs, tooltips, chat,
  toasts, tabs, toggles, checkboxes, radios, sliders, inputs, dropdowns,
  keycaps, ribbons, portraits, skill cards with cooldown, item cards,
  leaderboard rows, badges, chips, stars, scrollbars.
* HUD widgets: minimap frame, compass strip, currency counters with buy
  button, world nameplates, kill feed, interaction prompts, radial action
  wheel, party frames, ammo readouts, cinematic subtitles.
* Touch controls: virtual joystick, ABXY cluster, three crosshair reticles.
* 84 ready-made screens (Main Menu, HUD, Inventory, Shop, Settings, Pause,
  Dialog, World Map, Quest Log, Character, Results, Login, Loading,
  Character Select, Skill Tree, Defeat, Confirm, Achievements, Crafting,
  Chat, Mobile HUD) - HTML source + 4K PNG (3840x2160) for every theme.
* Offline interactive gallery (index.html): browse every screen, component
  and icon without an internet connection.
* Design tokens (JSON + CSS), OFL fonts (Inter + Montserrat), recolor guide.
* Unity package: everything imports as Sprites with 9-slice borders, plus
  UI Toolkit USS/UXML (5 screens), runtime C# (one-click theme switcher,
  popup animation, button juice, smooth status bars) and an editor helper.


WHY MEGAUI
----------
* 100% original parametric vector artwork - none of it is traced stock.
* Fully editable: one token file drives every color; one command recolors
  an entire theme without opening a vector editor.
* Built for production: consistent stroke weights, one type scale, shared
  grid across all 4 themes - mix components without visual drift.
* Tested: automated suite validates XML, counts, renders and packages
  (34/34 checks pass).


FORMATS
-------
SVG (masters) - PNG 4x (transparent) - HTML/CSS screen sources - 4K PNG
screens - JSON/CSS tokens - offline HTML gallery - Unity .unitypackage -
TTF fonts (OFL-1.1).


LICENSE NOTES
-------------
All MegaUI artwork, code and documentation: sold under your chosen Fab
license. Bundled fonts: Inter and Montserrat under SIL Open Font License 1.1
(OFL files included in fonts/).

Q: Was AI used in creating this content?
A: Yes - flagged "Created with AI" per Fab policy. All vector geometry is
   original parametric code written and reviewed for this product; no
   traced stock art and no third-party artwork is included.

Q: Do you allow AI training on your content?
A: No - enable the NoAI (no AI training) tag on the Standard license.

Q: Which engines is this product designed for?
A: Engine-agnostic. Primary formats: SVG, PNG (4x), HTML/CSS, JSON/CSS
   tokens, usable in Unity, Unreal, Godot, web and any PNG/SVG pipeline.
   A full Unity .unitypackage is included: 2672 PNGs import as Sprites
   with 9-slice borders, plus UI Toolkit USS/UXML and runtime C# scripts.

Q: Minimum Unity version?
A: Unity 2021.3 LTS or newer recommended.
