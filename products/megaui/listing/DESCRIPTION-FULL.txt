WHY MEGAUI
----------
Most UI packs are a folder of PNGs that fall apart the moment your design
changes color, resolution or screen size. MegaUI is a SYSTEM: every screen
is built from the same components, the same strokes, one type scale and one
24px grid — so anything mixes with anything else without visual drift. And
because every color flows from one token file, retheming is a text edit, not
an afternoon of Photoshop.

- 100% original parametric vector artwork — nothing traced, nothing stock.
- Consistent production grid across all four themes.
- Ships with source (SVG + HTML/CSS), not just flat images.
- Tested by an automated suite: XML validity, counts, renders, packaging.

HOW TO USE IT
-------------
1) Open index.html (offline gallery) and pick a theme.
2) Engine-agnostic path: copy SVGs into Figma/Illustrator/Inkscape, or drop
   the 4x PNGs into your engine/UI of choice (Godot, Unreal, GameMaker,
   Construct, web, Unity).
3) Unity path: import the .unitypackage, drag sprites onto a Canvas
   (9-slice already set), or open the UXML screens in UI Builder; attach
   the C# scripts for theme switching, popups and animated bars.
4) Want your own colors? Edit the token file, run the recolor command,
   done — see docs/RECLOUR.md.

A: All of them. The package is engine-agnostic (SVG/PNG/HTML/CSS); a full
   .unitypackage is included for Unity. Works with Unreal, Godot, GameMaker,
   Construct, LÖVE, web front-ends, and anything that draws an image.

Q: What Unity version do I need?
A: 2021.3 LTS or newer. Sprites + UI Toolkit tested; no other dependencies.

Q: Does it work with URP/HDRP?
A: Yes — it is pure 2D sprites/UI, so Built-in, URP and HDRP all work.

Q: How do I install it?
A: Double-click the .unitypackage inside Unity and import everything (or
