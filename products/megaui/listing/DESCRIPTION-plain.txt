MegaUI - Game UI Design System
================================

THE COMPLETE GAME UI KIT — 4 THEMES, 2672 COMPONENTS, 244 ICONS, 84 SCREENS IN 4K.


WHAT'S INSIDE
-------------
* 4 hand-crafted themes: Dark Fantasy, Sci-Fi Neon, Clean Royal, Pixel Retro.
* 2672 editable vector components (SVG) + the same 2672 PNGs at 4x resolution.
* 9 button shapes x 4 states x 4 kinds, per theme.
* 244 original icons on a shared 24px grid, tinted per theme.
* Bars, rings, slots (4 sizes x rarities), panels, dialogs, tooltips, chat,
  toasts, tabs, toggles, checkboxes, radios, sliders, inputs, dropdowns,
  keycaps, ribbons, portraits, skill cards with cooldown, item cards,
  leaderboard rows, badges, chips, stars, scrollbars.
* 84 ready-made screens (Main Menu, HUD, Inventory, Shop, Settings, Pause,
  Dialog, World Map, Quest Log, Character, Results, Login, Loading, Character
  Select, Skill Tree, Defeat, Confirm, Achievements, Crafting, Chat, Mobile
  HUD) - source + 4K PNG (3840x2160) for every theme.
* Touch controls: virtual joystick, ABXY cluster, 3 crosshair reticles.
* Meta overlays: world nameplates, kill feed, interaction prompts, radial
  action wheel, party frames, ammo/charges readout, cinematic subtitles.
* Offline interactive gallery (index.html): browse every screen, component
  and icon without an internet connection.
* Design tokens (JSON + CSS), OFL fonts (Inter + Montserrat), recolor guide.
* Unity package: everything imports as Sprites with 9-slice borders, plus
  UI Toolkit USS/UXML (5 screens), runtime C# (one-click theme switcher,
  popup animation, button juice, smooth status bars) and an editor helper.


WHY MEGAUI
----------
* 100% original parametric vector artwork - none of it is traced stock.
* Fully editable: one token file drives every color; one command recolors
  an entire theme without opening a vector editor.
* Built for production: consistent stroke weights, one type scale, shared
  grid across all 4 themes - mix components without visual drift.
* Tested: automated suite validates XML, counts, renders and packages.


FORMATS
-------
SVG (masters) - PNG 4x (transparent) - HTML/CSS screen sources - 4K PNG
screens - JSON/CSS tokens - offline HTML gallery - Unity .unitypackage -
TTF fonts (OFL-1.1).
