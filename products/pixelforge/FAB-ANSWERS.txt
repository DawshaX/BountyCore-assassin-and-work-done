3. DESCRIPTION  (long, narrative — plain text, no markdown symbols)
===============================================================================
PASTE (whole block):

PixelForge is an offline sprite sheet maker and pixel art studio. It runs
straight from a single HTML file in any modern browser - double-click, done.
No installation, no account, no internet, no telemetry.

WHY IT EXISTS
Building sprite sheets by hand is slow: align frames, add padding, prevent
texture bleeding, resize for engine limits, export in the right format.
PixelForge does all of it in one place, with a live animation preview before
you export.

WHAT IT DOES
- Import PNG/JPG/WEBP/GIF images by drag & drop or file picker
- One-click "Convert to pixel art": pixel size slider, 13 palettes
  (including DawnBringer 16 and PICO-8), dithering (none/Floyd-Steinberg/
  Bayer), auto palette from your own image
- Sheet layouts: shelf (tight pack), horizontal strip, vertical strip,
  uniform grid with manual column count
- Padding, edge extrusion (prevents texture bleeding), transparent-edge
  trimming, output scale 1x/2x/4x/8x
- Max texture size (1024/2048/4096/8192) with automatic multi-page split -
  every page verified to fit, with a warning if a single frame is too large
- Live animation preview: FPS control, loop/ping-pong/once modes, zoom,
  click-to-set sprite pivot points
- Undo/redo everywhere, batch frame rename, frame reorder

EXPORT FORMATS
- Sprite sheet as PNG (splits into page files when over the max texture)
- Animated GIF
- Atlas JSON in 4 formats: Generic JSON, Phaser 3, Aseprite, CSS sprite
- Frames ZIP and an ALL-in-ZIP bundle (sheet + GIF + JSON + README)

HOW TO USE (3 steps)
1. Open index.html in your browser
2. Drop your images in, adjust pixelate/layout settings
3. Press PNG, GIF, ATLAS or ALL (ZIP) - files download instantly

FILES INCLUDED IN THE DOWNLOAD
index.html, style.css, js/ sources, README.md, LICENSE.txt, CHANGELOG.md,
THIRD-PARTY.txt (open-source GIF libraries licenses). Total under 50 KB.
Everything runs locally from your disk.

REQUIREMENTS
Any current browser (Chrome, Edge, Firefox, Safari). Works from file:// with
no server. 100% offline.

LICENSE
Proprietary EULA (LICENSE.txt): personal and commercial use in your games
and projects, no resale or redistribution of the source itself.

Link to documentation and future updates:
https://github.com/DawshaX/BountyCore-assassin-and-work-done/releases/tag/pixelforge-v1.1.3

AI TRANSPARENCY
Listing images include AI-generated demonstration photos. The application
itself is deterministic code with no AI, no accounts and no network calls
at runtime.

10. FAQ  (section header: click "+ Add FAQ")
===============================================================================
Q: Does PixelForge need internet or an account?
A: No. It runs 100% offline from a local HTML file. No login, no install,
   no telemetry, no AI at runtime.

Q: What file formats can I export?
A: PNG sprite sheet (auto split into multiple pages when over the max
   texture size), animated GIF, atlas JSON (Generic, Phaser 3, Aseprite),
   CSS sprite sheet, frames ZIP, and an all-in-one ZIP bundle.

Q: Will the output work in Unity, Unreal, or Godot?
A: Yes. Exports are standard PNG/GIF/JSON files. The Generic JSON contains
   frame rectangles, sizes and pivots; the CSS format works directly on
   web projects. Engine-agnostic by design.

Q: Do I need to be a pixel artist to use it?
A: No. Import any photo or artwork and use one-click conversion with 13
   color palettes, dithering and edge extrusion. Or use it purely as a
   sheet packer for sprites you already made.

Q: Is this a subscription?
A: No. One-time purchase, lifetime use, free updates within the version
   line.

Q: What is included in the download?
A: A single ZIP under 50 KB containing the full application
   (index.html + style.css + js/), README.md, LICENSE.txt, CHANGELOG.md
   and THIRD-PARTY.txt. Open index.html and start working.
