PixelForge — Example Project (v1.1.3)
=====================================
This is a CONSUMER example: it contains output produced by PixelForge
(a 4-frame sprite sheet + its atlas JSON) so you can see exactly what the
tool exports and how it plugs into a Unity project.

It does NOT contain the PixelForge plugin itself.

How to use
----------
1. Install PixelForge from Fab (import PixelForge-Unity-v1.1.3.unitypackage).
2. Copy Assets/Example/ into your own project's Assets folder (or open
   this folder as a Unity project).
3. Select SampleSheet.png -> Texture Type: Sprite (2D and UI) -> Apply,
   then open the Sprite Editor to see the 4 frames.
4. SampleSheet.json matches the sheet rectangles/pivots (Generic atlas
   format) — use it to slice, or to drive a runtime loader.

Produced with PixelForge Sprite Sheet Maker — https://www.fab.com
