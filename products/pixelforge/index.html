    HOW IT WORKS

    1. Import — drop images or a whole folder (PNG · JPG · WEBP · animated GIF = one frame per GIF frame). Drag list items to reorder.
    2. Pixelate — shrink + quantize to an auto palette from your art, or a retro palette, with optional dithering.
    3. Pack — grid / tight shelf / strips; trim, padding, extrusion, multi-page if it exceeds the texture size.
    4. Preview — play the animation, click PIVOT to set rotation points (exported to JSON).
    5. Export — PNG sheet(s) + atlas (Generic / Phaser / Aseprite / CSS) + animated GIF, or a ZIP with everything.
    6. Undo/Redo — Ctrl+Z / Ctrl+Y anywhere.

    Everything runs 100% offline in your browser. No uploads, no accounts, no watermarks.
